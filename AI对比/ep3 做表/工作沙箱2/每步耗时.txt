## 技术线路（6 段）

```
S0 环境勘查      → 目录/Python/依赖(pdfplumber缺失)/LibreOffice(缺失) 判定
S1 模板逆向      → openpyxl 全量 dump（单元格/公式/合并/列宽行高）→ 分组结构 dump → template_map.json
S2 图纸解析      → PyMuPDF 326页文本提取 → 判定"文字层"分布 → 定位表格页(P21/P22)
S3 数据提取      → pdfplumber 判表 → 渲染裁切＋放大目视判读 → 合计行/列闭合校验纠错
S4 填表          → openpyxl 写图纸数量+备注（不动公式/样式/合并）→ 保留模板计算结构
S5 重算与保真    → LibreOffice headless 重算 → xlsx XML 层还原精确列宽（不碰 sheetData，保缓存）
S6 交付文档      → validation_report.md / fill_log.md / final.xlsx
```
