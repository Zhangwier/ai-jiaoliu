# ep3 补测提示词（A / B / C 三份）

> 目的：把三份 `final.xlsx` 从"能看"推到"能交付"，好让 PPT 拿得出手。
> 原则：**做法三份不同，自检三份相同**。做法一样了，实验就没得讲了。

---

## 使用前

1. **在同一会话里继续**，不要新开——要保留沙箱里已有的产物和上下文。
2. 先把 `final.xlsx` 复制成 `final_v1.xlsx` 存档，别覆盖证据。
3. 三份提示词分别粘给对应会话，末尾的「共用块」三份都要加。
4. 目标是"每档可追、未完成隔离、打开有数"，**不是**"整册工程量审定通过"。后者一轮做不完，也别在 PPT 里这么说。

---

## 共用块（三份末尾都粘这一段）

```text
【共用的交付与自检约定】

一、产物
1. 原 final.xlsx 保留不动，新产物另存 final_v2.xlsx（同目录）。
2. 另交 交付说明.md，必须含四节：
   ① 每个厚度档的图纸数量来源页 + 复核明细来源页
   ② 未完成清单：页码、原因、缺什么字段、谁该补
   ③ 与 v1 的差异对照（哪些数变了、为什么变）
   ④ 本次重算证据（用什么工具、什么时间、抽样哪几个格子从多少变成多少）

二、时间
时间盒 120 分钟。做不完不要硬凑，写进未完成清单。
已有中间产物（OCR/表格 CSV/脚本）优先复用，不要从头重跑。

三、自检（交付前逐条跑，把结果贴进交付说明）
S1 打开即见数：所有公式格都能读到缓存值（data_only 读到非空），空缓存数 = 0。
S2 错误值：全表无 #REF! / #NAME? / #VALUE! / #DIV/0!。
   （模板自带的 横隔板!D140 = #REF! 属于必须修的一项，修完在说明里写清怎么修的。）
S3 模板保真：sheet 名与顺序、表头文字、合并单元格数、列宽、数字格式。
   与模板有出入的，逐项列清单并说明为什么必须改。
S4 图纸数量口径：必须是新沙图纸的数，不得留潭州 2,989,013.3。
S5 明细可追：每个厚度档的复核数量，至少能追到一行"长×宽×厚×数量"的构件明细；
   追不到的档，标"未完成 + 原因"，不许用图纸汇总值填单件重顶上。
S6 汇总覆盖：图纸上出现的每个厚度值，都要有对应的汇总列/行，不许只剩 7 个桶。
S7 未完成隔离：待确认行、缺尺寸行单独区块或单独标记，不得混进合计。

四、纪律
1. 只写你实际验证过的结论；不确定的写"待核"，不许写成"已通过"。
2. 不许为了通过自检把公式换成数值。
3. 不许为了凑数编造长、宽、厚、数量。读不出来就写读不出来。
```

## A 组提示词（保持"一句话交办"的风格，只抬目标）

```text
上一版还不是算出来的：主梁 44 行是把图纸汇总值写进"单件重"、数量填 1，等于没算；
横隔板那段是真算的，所以总重差 146 kg 全落在它身上。

这一版请把主梁也做成算出来的：每个厚度档的复核数量，都要能追到具体板件的长×宽×厚×数量；
追不到的档，写出页码和原因，标未完成，不要拿汇总值顶上。图纸数量换成新沙的。
结果另存 final_v2.xlsx，模板的 sheet、表头、合并单元格、公式都要在，打开就要有数。

交付前把"每档来源页、未完成清单、跟上一版差在哪"写进 交付说明.md。
```

> 这份故意只有五句。**不要给它加步骤**——A 组的实验条件就是"不告诉它怎么做"。
> 它自己选哪条路（读汇总表还是啃 44 张节段图）本身就是这组要展示的东西。

## B 组提示词（详细约束，把上次卡死它的那条松开）

```text
上一版的问题是：为了让模板一格不动，复核列原样留着潭州的数据（G4:G13 与模板逐格相同），
12 mm 档出现"图纸 193,459.1 / 复核 323,303.3"这种两边不是一个项目的对比；
另外 梁底挡块!I8、附属预埋件!I11 两个 =F-G 被备注文字覆盖，公式数从 1,438 掉到 1,436。

这一版按下面的规则重做，原 final.xlsx 不动，另存 final_v2.xlsx。

【可以动结构，但必须同步】
1. 允许在 合计数量 增删厚度行、在明细表增删厚度列，但每处改动都要：
   同步所有跨 sheet 引用；在 fill_log_v2.md 记"改了什么、影响哪些格、改前改后"。
2. 模板的 sheet 名与顺序、表头文字、列宽、数字格式、边框字形：保持。
3. 合并单元格：原有 735 个必须逐一保留；新增行按同组模板行复制样式，不许新建默认样式。

【数据】
4. 图纸数量列（D/E）按新沙图纸重填，每档在备注写来源页码；
   新沙没有的档（如 δ30、δ50）留空并注明"图纸无此档"，不许填 0 冒充。
5. 复核数量列（G）不许留模板值。每个档要么给出构件级明细支撑，要么标"未完成 + 原因"。
6. 图纸数量与复核数量分列，差异列必须是公式 =G-F。

【公式与计算】
7. 单件重、合计重量、小计、按厚度汇总、复核数量、差异全部用公式；汇总用 SUMIF/SUMIFS，
   不许把汇总结果写成常量。
8. 明细里 单件重 =（长/1000）×（宽/1000）×（厚/1000）×7850；非矩形板件（腹板、加劲板）
   按净面积 A 计：(A)×(厚/1000)×7850，并在表里留出面积列。
   严禁把图纸的"按材质×板厚汇总值"直接填进单件重。
9. 修掉 横隔板!D140 的 =#REF!（模板自带缺陷），修完在说明里写清改成了什么。
10. 备注只能写进备注列，不许占用公式单元格。

【交付】
11. 必须用 LibreOffice 无头重算并保存，保证 Excel 打开有缓存值；不许用数值替换公式。
12. 交付说明.md 写清：每档来源页、未完成清单、公式数 v1→v2、合并单元格数、错误值数量、
    抽样重算记录。
```

> 关键改动是第 1 条：上次"不插删行"这条硬约束把它锁死在新沙装不进模板的死局里。
> 松开成"可以动，但要同步并记账"，它才有机会把 2,107.7 t 补进去——这才是企业里真实的做法。

## C 组提示词（分阶段，补一道"交付验收"闸门）

```text
上一版阶段产物最全，但最终文件有三处硬伤：
① 11,476 个公式全无缓存值，Excel 打开是空白；
② 按厚度汇总只剩 7 个桶（12/14/16/20/24/30/40），实际厚度有 8/10/28/32/36/44/48/50/60/80/100 等，
   桶外 2,897,899 kg 不进汇总，覆盖率 68.6%；
③ 图纸数量列仍是潭州 2,989,013.3，U 列只有 16 个块首行有值，重算后 G15=7,040,544，
   对图纸差 +135.5%，这个百分比没有业务意义。

原 final.xlsx 不动，另存 final_v2.xlsx。按阶段推进，每阶段落盘 + 写 handoff。

阶段 E2 修写入层
- A/B 列是合并单元格锚点，上次 728 格因此为空。改为先写值再合并，或逐行落值后合并。
- 933 行有数量但缺长宽，这些行要么补齐尺寸，要么从合计中剔除并单列"缺尺寸清单"，
  不许继续按 0 计入合计。
- 142 行标着"校验 fail"的，逐行给结论：可修 / 应删 / 待核，并在表内分开标记。

阶段 G2 交付验收（新加，独立于 F）
用 data_only 打开 final_v2.xlsx，逐条验：
1. 空缓存公式数 = 0；
2. 无 #REF!/#NAME?/#VALUE!；模板自带 横隔板!D140 必须修掉；
3. 合并单元格 735 个是否齐；主梁明细行数、块首行 SUMIF 范围是否随插行扩展；
4. 汇总桶是否覆盖图纸实际厚度（按新沙 16 个厚度档重建，不许沿用 7 个桶）；
5. 图纸数量列是否已换成新沙，每档是否有来源页；
6. 随机抽 10 行，独立复算 长×宽×厚×7850×数量，与表内 J 列比对。
任一条不过 → 回阶段 E2 返修，最多 3 轮。

阶段 H 收尾
- 重跑 LibreOffice 重算并保存 final_v2.xlsx（这是 ① 的唯一解，别用 openpyxl 算完再写死）。
- 写 交付说明.md：每档来源页、未完成清单、G2 六条的逐条结论、v1→v2 差异对照。

可以复用 out/ 里已有的 raw_tables.csv、normalized_tables.csv、page_manifest.csv，
不要重跑 155 页 OCR；只有某档缺明细时，才单独补跑对应页。
```

> C 组上次是"阶段验收 PASS 不等于交付可用"的活标本。加 G2 这一道闸，正好把 PPT 里那页的结论变成"加了闸就能过"。

## 补测之后 PPT 怎么改

三种结果，三种改法——**先看数再说，别预设结论**：

1. **三份都过 G2**：PPT 的落点改成"同一条验收线，三种组织方式都能交付，差别在耗时与过程可控性"。
   第 3/4/5 页的三张"硬伤卡"换成三张"耗时-返修轮次-产物齐全度"对照，结论改成
   "多 Agent 不是更强，是把返修成本前置了"。
2. **只有 B 或 C 过**：保留现在的三页结构，把"过的那组"的 v2 截图放进第 6 页当验收样例，
   标题从"三种交办方式的差异"改成"哪种交办方式能一次过验收"。
3. **三份都没过**：不要硬讲成"都不行"。改成"三个都在同一个检查点上栽了"，
   把 G2 那六条直接做成 PPT 的验收清单页——这反而是最有企业价值的一页。

无论哪种，都要在页脚注明：**这是补测轮（v2），与首次结果（v1）分开陈述，不合并统计**。
