# AI 交流分享：从原理到实践的模型对比材料

一份面向混合听众的 AI 经验分享 PPT，以及三组真实任务上的多模型对比原始材料。

> **数据边界**：`AI对比/` 下含真实工程项目的图纸与清单（`桥墩挡块.pdf`、
> `ep2 报告/源文件/`、`ep3 做表/源文件/`），可见设计/复核/审核人员姓名与合同金额。
> 这批材料只用于说明“AI 交付物看起来像样，仍需人来核”，**不构成设计成果或计量依据**。
> `ep3 做表` 里 101MB 的原始施工图未入库（见 `.gitignore`），仓库只保留裁切后的数量表页。
> `ep4 小虎沥实战` 含真实工程图与审核信息，整目录不入库，仅保留在本地。
> 公开传播前请确认是否符合所在单位的资料管理要求。

## 三组对比

### ep1 识图 · 桥墩挡块审查（任务 1）

同一张 3 页图纸、同一句提示词，10 组“工作常用”配置各出一份审查工作簿：

> 审查这个有没有问题结果输出excel给我

评估口径见 `核对/模型对比口径v3.md`：三个诊断检查点 K1/K2/K3。
**分母是 3，不是全部真实问题数**，不能写成“准确率”。

### ep1 识图 · 鹈鹕动画（任务 2）

同一句提示词，10 组配置各生成一个 SVG 鹈鹕骑自行车动画：

> 创建一个HTML，内容是SVG绘制一个鹈鹕骑自行车的2D动画，你不需要任何测试

- 条件：**一次生成、无历史记忆**；`不需要任何测试` 是原始实验条件。
- 素材：`核对/鹈鹕原始结果/A–J.html`，无外部依赖，可离线播放。
- `核对/鹈鹕配置映射.json` 里的 `source` 已改成仓库内相对路径，指回 `AI对比/ep1 识图/`。

### ep2 报告 · 修编报告（任务 3）

> 根据提供的工程量清单完成修编报告，其余文件为查阅变更原因参考。

只有 4 个配置参加（opus / trae-auto / workbuddy-auto-flat / deepseek），其余不记失败。

### ep3 做表 · 钢结构计算底稿

> 提示词见 `AI对比/ep3 做表/提示词.txt`（两版）。七个工作沙箱记录同一任务的逐轮迭代，
> `工作沙箱N/out/` 是各轮中间产物与校验报告，`结论1.txt`、`补测核验结论.md` 是核验结论。

## 使用边界

- 图纸核对结论只覆盖**图内一致性、单位、尺寸分段、表与公式的算术关系**，
  **不含**抗震承载力、锚固长度、施工合格判定；也不构成任何设计修改意见。
- 各模型输出中的工程结论一律视为“待核”，不得直接用于下料、计量或施工。
- `ep3 做表` 的 101MB 原始施工图保留在本地工程目录，未提交到本仓库。
