> 这批材料仅用于说明"AI 交付物看起来像样，仍需人来核"，**不构成设计成果或计量依据**。

## 两组对比实验

### ep1 识图 · 鹈鹕（任务 2）

同一句提示词，10 组"工作常用"配置各生成一个 SVG 鹈鹕骑自行车动画：

> 创建一个HTML，内容是SVG绘制一个鹈鹕骑自行车的2D动画，你不需要任何测试

- 条件：**一次生成、无历史记忆**；`不需要任何测试`是原始实验条件。
- 素材：`完善版01配套/鹈鹕原始结果/A–J.html`，无外部依赖，可离线播放。
- 已知问题：`鹈鹕配置映射.json` 里 10 条 `source` 指向 `D:\MG\program\AI对比\...`（少了 `ai交流\` 一层），
  实际目录是本仓库的 `AI对比/ep1 识图/`。

### ep1 识图 · 桥墩挡块审查（任务 1）

同一张 3 页图纸、同一句提示词（`审查这个有没有问题结果输出excel给我`），10 组配置各出一份审查工作簿。

评估口径见 `完善版01配套/模型对比口径v3.md`：三个诊断检查点 K1/K2/K3，
**分母是 3，不是全部真实问题数**，不能写成"准确率"。

### ep2 做表 · 修编报告（任务 3）

`根据提供的工程量清单完成修编报告，其余文件为查阅变更原因参考。`
只有 4 个配置参加（opus / trae-auto / workbuddy-auto-flat / deepseek），其余不记失败。

## 数据使用边界

- `AI对比/ep1 识图/桥墩挡块.pdf` 与 `任务3源文件/` 为真实项目资料，含设计/审核人员姓名与合同金额。
- 图纸核对结论只覆盖**图内一致性、单位、尺寸分段、表与公式的算术关系**，
  **不含**抗震承载力、锚固长度、施工合格判定；也不构成任何设计修改意见。
- 各模型输出中的工程结论一律视为"待核"，不得直接用于下料、计量或施工。
